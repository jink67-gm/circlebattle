# 서클배틀

초등학교 6학년 「원의 넓이」 × 실시간 팀 대전 웹게임

## 완성 — STEP 21 전체 테스트까지 끝남

### 수업에서 쓰는 순서
1. **선생님 기기(TV 연결)**: [교사용] → PIN → 방 설정 → [방 만들기] → 화면의 **방 번호 4자리**를 알려 주기
2. **학생 태블릿**: 닉네임 + 방 번호 → [참가하기] → 캐릭터 고르기
3. 선생님: 팀 확인(이름 누르면 옮기기, [팀 섞기]) → **[게임 시작]**
4. 경기 후: 결과 화면 → **[📊 학습 결과 보기]** → 필요하면 CSV 내려받기 → [대기방으로] → 다음 경기
- 인터넷이 없어도 학생 각자 [혼자 연습하기]는 됩니다.

### 처음 한 번만: 배포
1. GitHub에 저장소를 만들고 이 폴더의 파일을 모두 올리기 (`index.html`이 맨 위에 오게)
2. 저장소 **Settings → Pages → Branch: main / (root) → Save** → 1~2분 뒤 `https://아이디.github.io/저장소이름/`
3. Firebase 콘솔 → Realtime Database → 규칙에 `circleBattle` 규칙 추가 (아래 STEP 16의 "Firebase 준비")
4. `js/config.js`의 `TEACHER_PIN`(처음 `0000`)을 바꾸기
5. 학생 태블릿에서 주소를 열고 **홈 화면에 추가** (STEP 20)
- 모든 파일 경로가 상대 경로라서 저장소 이름이 무엇이든 그대로 동작합니다.

### STEP 21에서 한 것
**우리 반 그대로 시험**: 가짜 Firebase로 선생님 기기 1대 + 학생 기기 9대를 한 번에 띄우고,
학생 9명이 스스로 움직이고·쏘고·특수기를 쓰고·수학 미션을 실제 화면으로 푸는 5분 경기를 끝까지 진행
- 10대 모두 같은 점수·같은 승리 팀, 학생 화면의 내 기록 = 교사 기기 기록, CSV 줄 수 = 푼 문제 수
- 경기 중 방해 상황: 학생 새로고침 → 다시 참가, 와이파이 9초 끊김, 설정에서 나갔다가 [경기로 돌아가기] — 모두 이어서 진행
- 2경기: 선생님도 참가(5 대 5, 봇 없음), 팀 섞기, 새 경기 초기화, 오늘 전체 학습 결과(2경기, 선생님 제외 9명)
- 10초마다 모든 기기 비교(31번): 30번은 점수·존·시간·체력이 모두 같음. 1번은 점수가 오르는 바로 그 순간을 잡아
  학생 기기에 0.1초 늦게 반영된 것 (다음 비교부터 다시 같음). 다른 친구 위치 차이는 최대 약 2m (네트워크로 부드럽게 따라가기)
- 10대 모두 자바스크립트 오류 0

**기획서 대조**: 따로 점검해 구체적 요구사항 92개 중 80개가 그대로, 나머지는 선생님 결정이나 교육적으로 더 나은 방식으로 다르게 구현됨을 확인.
그 과정에서 찾은 문제를 고침:
- **빈자리 봇이 가만히 서 있던 문제** → 에너지 존으로 가서 자리를 지키고, 사거리 안 상대를 쏨 (학생보다 약하게: 반응이 느리고 조준이 흔들림, 특수기·미션은 안 씀)
  - 고치기 전 시험: 봇이 있는 팀이 0 : 31로 짐 (실제로는 4명이 5명과 싸운 셈)
- "정답!"을 보여주는 0.6초 사이에 경기가 끝나거나 재충전되면 정답 기록이 사라지던 문제
- 고르기 문제(TYPE 4)도 기획서 39번대로: 첫 오답 "다시 생각해보세요", 두 번째 오답에 힌트
- 교사 기기가 학생 명령을 확인: 탄약보다 많이 쏘는 명령, 한 경기 문제 수를 넘는 미션 결과는 무시
- 문구: "9999번 방을 찾을 수 없어요", "방 번호 1234 — 학생들은 …", 제목 "서클배틀"로 통일

### 알아 둘 점 (한계)
- 교사 기기가 경기 계산을 맡으므로, 경기 중에는 **교사 기기를 켜 두고 다른 탭으로 옮기지 마세요.**
- 데이터 사용량: 10명이 계속 싸우는 경기에서 학생 기기 한 대당 1초에 약 11KB (8분 경기 ≈ 반 전체 50MB).
  Firebase 무료 한도(한 달 10GB)로 약 200경기.
- 실제 Firebase 서버와 실제 태블릿은 이 개발 환경에서 연결할 수 없어, 가짜 Firebase와 태블릿 화면 흉내로 시험했습니다.
  처음에는 태블릿 2~3대로 짧게 시험해 보세요.
- 교사 PIN은 GitHub에서 누구나 볼 수 있는 가벼운 잠금입니다.

## STEP 20 (태블릿 최적화)

### 더 부드럽게 (성능)
- 움직이지 않는 맵은 **뒤쪽 캔버스에 한 번만** 그리고, 매 프레임에는 움직이는 것만 그림
- **화질 자동 조절**: 경기 중 1초에 45장보다 적게 그려지면 해상도를 한 단계씩 낮춤 (2배 → 1.5배 → 1.13배 → 1배)
  - ⚙ 환경설정 → 화질: **자동**(기본) / **선명하게** / **빠르게** — 기기마다 기억
- 측정 (10명이 싸우는 복잡한 장면, CPU를 일부러 느리게 해서 오래된 태블릿 흉내)

  | 기기 크기 | 전 | 후 (자동) |
  |---|---|---|
  | iPad, CPU 4배 느림 | 1초에 24~27장 | 45장 |
  | iPad, CPU 6배 느림 | 16장 | 33장 |
  | 크롬북, CPU 6배 느림 | 33장 | 39장 |
- 글꼴(Jua)을 나중에 불러와서, 학교 인터넷이 느리거나 글꼴 서버가 막혀도 첫 화면이 바로 뜸

### 손가락에 맞는 크기 (터치 기기에서만, PC 화면은 그대로)
| | 휴대폰 | 7인치 탭 | 10인치 태블릿 |
|---|---|---|---|
| 이동·공격 조이스틱 | 110px | 140px | 140px |
| 특수기 버튼 | 84×56 | 110×76 | 132×88 |
| 반지름 r2·r3·r4 | 46×44 | 56×54 | 64×64 |
| 수학 미션 숫자판 | 44px | 50px | 62px |
| ⚙ | 44px | 50px | 54px |
- 모든 버튼 44px 이상, 특수기 버튼이 공격 조이스틱·탄약 표시와 겹치지 않게 배치 (6가지 화면 크기로 확인)
- 휴대폰 노치·둥근 모서리에 버튼이 가리지 않게 안전 여백

### 태블릿에서 생기는 문제 막기
- **경기·대기방에서는 화면이 꺼지지 않음** (크롬·삼성 인터넷, iPad Safari 16.4 이상)
- 두 손가락 확대, 두 번 눌러 확대, 길게 눌러 메뉴, 당겨서 새로고침 막기
- 세로로 들면 "가로로 돌려 주세요" 안내 (이미 있던 기능)

### 홈 화면에 추가 (앱처럼 전체 화면으로)
- 아이콘·이름(서클배틀)·가로 전체 화면 설정 (`manifest.json`, `icons/`)
- iPad: Safari → 공유 → **홈 화면에 추가** / 안드로이드: 크롬 메뉴 → **홈 화면에 추가**
- 홈 화면에서 열면 주소창이 없어 경기장이 더 크게 보입니다.

### 수업 전 태블릿 준비 (선생님 체크리스트)
1. 태블릿을 **가로**로, 화면 회전 잠금은 가로로
2. 오래된 iPad(iPadOS 16.3 이하)는 설정 → 디스플레이 → **자동 잠금: 안 함** (화면 꺼짐 방지가 안 되는 기기)
3. 학생이 다른 앱으로 나가지 않게 하려면 iPad **사용법 유도(Guided Access)** / 안드로이드 **앱 고정**
4. 교사 기기(TV)는 충전기에 연결 — 교사 기기가 꺼지면 모든 경기가 멈춥니다
5. 처음 한 번 "홈 화면에 추가" 해 두면 다음부터 아이콘으로 바로 실행

## STEP 19 (학습 결과)

### 경기 결과 화면 — 내 기록 (모든 학생 기기)
승리 팀과 팀 점수 아래에 **내 기록**이 나옵니다.
- 푼 문제 · 정답(정답률) · 점령 기여(㎡) · 공격 성공 · 지원 · 특수기
- 분류별 정답: 원의 넓이 / 반지름·지름 / 넓이 비교
- **순위는 보여주지 않습니다.** 대신 내 기록에 맞는 격려 한마디
- 멀티플레이: 기록은 교사 기기가 계산해서 학생 기기로 보냅니다.
  (받지 못하면 4초 뒤 내 기기의 수학 기록만이라도 보여줌)
- 관전하는 선생님 화면(TV): 개인 기록 대신 **우리 반 수학 미션** (팀별 정답 수, 전체 정답률)

### 교사용 학습 결과 (교사 기기에만)
열기: 경기 결과 화면의 **[📊 학습 결과 보기]**, 또는 교사 대기방의 **[📊 학습 결과]**
- **이번 경기 / 오늘 전체** (같은 기기 = 같은 학생으로 합쳐서, 몇 경기 했는지 표시)
- 반 전체: 참여 학생 수, 푼 문제, 전체 정답률, 평균 풀이 시간, 분류별 정답률 막대
- **다시 짚어 볼 문제**: 두 명 이상 푼 문제 중 정답률이 낮은 문제 (문제와 정답)
- **학생별 기록**: 닉네임 · 원의 넓이 / 반지름·지름 / 넓이 비교 (정답 수/푼 수) · 정답률 · 평균 풀이 시간 · 공격 성공 · 점령 기여 · 지원
  - 처음에는 가나다순, 제목을 누르면 정렬
  - **[학생별 표 가리기 (TV용)]**: TV에 띄울 때는 반 전체 요약만
- **CSV 내려받기** (엑셀에서 한글이 깨지지 않게 저장)
  - 학생별 요약: 닉네임, 팀, 경기 수, 푼 문제, 정답, 정답률, 분류별 정답/푼 수, 힌트 사용, 풀이를 본 문제, 평균 풀이 시간, 공격 성공, 점령 기여, 지원, 특수기
  - 문제별 풀이 기록: 경기 시각, 닉네임, 문제 번호, 유형(TYPE), 분류, 난이도, 문제, 정답, 결과(정답/힌트 후 정답/풀이 봄), 틀린 횟수, 풀이 시간, 보너스
- 기록은 **교사 기기에 저장**됩니다. 새로고침해도 남고, 최근 60경기까지 보관. [기록 지우기]는 두 번 눌러야 지워짐
- 선생님이 **[경기 끝내기]로 중간에 끝낸 경기**도 그때까지 푼 문제는 저장 ("중간에 끝냄")
- 혼자 연습은 저장하지 않습니다. (학생 자기 기기의 연습)

## STEP 18 (환경설정)

게임 화면 오른쪽 위 **⚙ 버튼** (PC는 **Esc** 키)
- **소리 · 화면**
  - 전체 음량 / 배경음 / 효과음 막대 (0~100, 기기마다 기억). 손을 떼면 들어 보기 소리
  - 소리 끄기/켜기 (PC의 M 키와 같음)
  - 전체화면 켜기/끄기 — 안드로이드 태블릿은 전체화면일 때 가로로 고정
    전체화면이 안 되는 기기(아이폰 등)는 "홈 화면에 추가" 안내
- **조작 설명**: 태블릿·PC 조작 (지금 쓰는 기기를 먼저, 휴대폰에서는 그 기기 것만),
  내 캐릭터의 기본 공격·특수기, 규칙 한눈에 보기 (존 넓이·점수, 에너지, 특수기 비용 = 원의 넓이, 승리 조건 — 지금 경기 설정 값으로)
- **나가기** (실수 방지: 두 번 눌러야 나감, 2.5초 지나면 원래대로)

| 누가 | 버튼 | 어떻게 되나요 |
|---|---|---|
| 혼자 연습 | 대기방으로 나가기 | 연습 경기를 끝내고 대기방으로 |
| 학생 기기 | 대기방으로 나가기 | 내 캐릭터는 경기장에서 잠시 빠짐(자리 비움). 대기방의 **[경기로 돌아가기]** 로 다시 들어가면 시작 지역에서 재등장 |
| 선생님 기기 | **경기 끝내기** | 경기가 결과 없이 끝나고 모든 학생 화면이 대기방으로 |
| 경기가 끝난 뒤 | 대기방으로 | 한 번에 대기방으로 |

- 혼자 연습 중에는 설정 창을 여는 동안 **경기가 멈춥니다** (시간·연습 상대·배경음).
- 여러 명이 하는 경기는 멈출 수 없어서 **계속 진행**됩니다. 내 캐릭터는 제자리에 서 있어요.
- 수학 미션을 푸는 중에 열어도 되고, 닫으면 풀던 문제로 돌아갑니다.

### 자리 비움 (멀티플레이)
학생이 경기 중에 나가거나, 태블릿이 잠들거나 와이파이가 끊겨 **6초 넘게 소식이 없으면**
그 학생의 캐릭터는 경기장에서 잠시 빠집니다. (에너지 존을 계속 막고 있거나 과녁이 되지 않게)
다시 연결되면 곧 시작 지역에서 재등장합니다. 시간은 `config.js`의 `NET.AWAY_SEC`.

## STEP 17 (사운드)

모든 효과음과 배경음은 **소리 파일 없이** 브라우저가 그 자리에서 만들어 냅니다. (직접 만든 원본 소리)
소리는 `js/audio.js`(AudioManager) 한 곳에서 관리합니다.

| 언제 | 소리 |
|---|---|
| 버튼 누르기 / 미션 숫자판 | 짧은 톡 / 더 작은 톡 |
| 공격 | 캐릭터마다 다름 (직선탄 슝 · 엔지니어 구체 뿅 · 가디언 충격파 쉬익) |
| 내 공격이 맞음 / 내가 맞음 | 딱 (명중) / 퍽 (피격) |
| 탄약 한 칸 충전 | 작은 띵 |
| 특수기 | **반지름이 클수록 낮고 긴 소리** (r2 → r3 → r4, 넓이가 커지는 느낌) · 순간이동 · 폭발 |
| 수학 미션 | 열기 · 오답(부드러운 두 음) · 정답(도-미-솔) · 보너스 고르기 |
| 에너지 존 | 점령 시작 · 점령 완료 · 점령 풀림 · 점수 획득 |
| 체력 0 / 재등장 | 에너지가 흩어지는 소리 / 모이는 소리 |
| 시작 | 3 · 2 · 1 · 시작! |
| 경기 끝 | 승리 · 패배 · 무승부 (관전하는 선생님 화면은 축하 소리) |
| 배경음 | 경기 중에만 잔잔한 반복 곡, **연장전에는 빨라짐** |

- 브라우저 규칙 때문에 **화면을 한 번 누른 뒤부터** 소리가 납니다.
- 음량: 전체 / 배경음 / 효과음을 이 기기에 기억합니다. 환경설정(⚙) 화면은 STEP 18.
  처음 값은 `config.js`의 `SOUND.DEFAULT_VOLUME`, 전체 크기는 `SOUND.OUTPUT_GAIN`.
- PC에서 **M 키** = 소리 끄기/켜기 (닉네임 칸에 m을 칠 때는 제외)
- 멀티플레이: 학생 기기도 같은 소리가 납니다. 점령·점수·체력 변화는 각 기기가 화면의 변화를 보고 소리를 내므로 네트워크로 따로 보내지 않습니다.
- 원하는 소리 파일로 바꾸고 싶으면 `config.js`의 `SOUND.FILES`에 적으세요.
  예) `FILES: { correct: 'sounds/correct.mp3', bgm: 'sounds/bgm.mp3' }` — 파일이 없거나 못 불러오면 만들어 내는 소리를 씁니다.
  (파일은 GitHub Pages 주소로 열 때만 불러올 수 있고, index.html을 더블클릭해서 열면 만들어 내는 소리를 씁니다)
- 소리를 지원하지 않는 브라우저에서도 게임은 그대로 됩니다.

## STEP 16 (멀티플레이 — Firebase)

학생 기기들이 교사 방에 들어와 **같은 경기**를 합니다.
- 교사: [교사용] → PIN → 설정 → [방 만들기] → 화면에 나온 **방 번호 4자리**를 알려 주기
- 학생: 닉네임 + 방 번호 → [참가하기] → 캐릭터 고르기 → 선생님이 [게임 시작]을 누르면 모두 함께 3·2·1
- 교사 대기방: 학생이 들어오고 나가고 캐릭터를 바꾸는 것이 바로 보임. 팀 옮기기·팀 섞기는 학생 화면에도 바로 반영
  - 학생 이름 옆 ✕ = 내보내기 (학생 화면은 시작 화면으로, 방 번호로 다시 들어올 수 있음)
  - [방 닫기] → 모든 학생 화면이 시작 화면으로
- 경기가 끝나면 교사가 [대기방으로] → 학생들도 결과를 보고 [대기방으로] → 다음 경기
  (결과를 보고 있던 학생도 선생님이 새 경기를 시작하면 자동으로 들어감)

### 어떻게 맞추나요? (교사 기기가 심판)
- 체력·에너지·명중·점령·점수·시간·특수기는 **교사 기기**가 계산해서 1초에 10번 보냅니다.
- 학생 기기는 **내 캐릭터 움직임만** 직접 계산하고(바로 반응), 위치를 1초에 12번 보냅니다.
- 쏘기·특수기·수학 미션 결과는 "명령"으로 보내고, 교사 기기가 받았다고 할 때까지 다시 보냅니다.
- 그래서 **교사 기기(TV 화면)는 경기 내내 켜 두어야** 합니다. 교사 기기가 잠들면 학생 화면에 "선생님 기기 연결이 끊겼어요"가 뜹니다.

### 연결이 끊겼을 때
| 상황 | 어떻게 되나요 |
|---|---|
| 학생 태블릿 와이파이가 잠깐 끊김 | "인터넷 연결이 끊겼어요" 표시 → 다시 연결되면 그대로 계속 |
| 학생이 새로고침 / 브라우저를 닫았다 다시 엶 | 같은 방 번호로 [참가하기] → 하던 경기로 바로 돌아감 (같은 기기면 같은 사람) |
| 경기 중에 새로 들어온 학생 | 이번 경기는 관전, 다음 경기부터 참가 |
| 교사 기기가 새로고침됨 | 학생 화면에 경고 → 교사가 다시 [교사용]→[방 만들기] 하면 **같은 방 번호**로 열리고 학생들이 그대로 남아 있음 |
| 인터넷이 아예 안 됨 | [혼자 연습하기]는 그대로 됨. 교사 방은 이 기기 안에서만 열리고 [+ 시험 학생]이 보임 |

### Firebase 준비 (처음 한 번)
1. Firebase 설정값은 `js/config.js`의 `FIREBASE`에 들어 있습니다. (웹 앱 설정값은 공개되어도 되는 값입니다)
2. Firebase 콘솔 → **Realtime Database → 규칙** 에서 `circleBattle` 부분을 **추가**합니다.
   다른 게임(예: 기존 게임)의 규칙은 지우지 말고 그 옆에 넣으세요.
```json
{
  "rules": {
    "circleBattle": {
      "rooms": {
        "$code": {
          ".read": true,
          ".write": true
        }
      }
    }
  }
}
```
   - 이미 다른 규칙이 있으면 `"rules": { ... }` 안에 `"circleBattle": { ... }` 덩어리만 쉼표로 이어 붙이면 됩니다.
   - "테스트 모드"(날짜가 지나면 막히는 규칙)만 있으면 날짜가 지난 뒤 방 만들기가 안 됩니다. 위 규칙을 넣어 두면 계속 됩니다.
   - 규칙에 막히면 교사 대기방에 "Firebase 데이터베이스 규칙이 막고 있어요"라고 나옵니다.
3. 데이터는 `circleBattle/rooms/방번호` 아래에만 저장되고, [방 닫기]를 누르면 지워집니다.
   (3시간이 지난 방 번호는 새 방이 다시 쓸 수 있습니다)

### 데이터 사용량 (무료 요금제로 충분)
- 경기 중 학생 기기 한 대가 받는 양: 조용할 때 1초에 약 4~6KB, 10명이 계속 싸우면 약 11KB (STEP 21 측정)
- 8분 경기 × 학생 9명 ≈ 20~50MB → 무료 한도(한 달 10GB)로 약 200경기 이상

### 시험용 주소
- `?test=1` : 인터넷이 되어도 교사 대기방에 [+ 시험 학생] 버튼 보이기
- `?dev=이름` : 한 컴퓨터의 여러 탭을 서로 다른 기기로 시험 (예: `index.html?dev=a`, `index.html?dev=b`)

## STEP 15 (교사용 방 생성)

화면 흐름: **시작 화면 [교사용] → PIN → 방 설정 → [방 만들기] → 교사용 대기방 → [게임 시작]**
- PIN은 `config.js`의 `TEACHER_PIN` 한 곳에서만 바꿉니다. (처음 값 `0000` — 꼭 바꿔 주세요)
  - GitHub Pages에서는 누구나 파일을 열어 볼 수 있으니 "학생이 실수로 들어오지 않게 하는 가벼운 잠금"으로 생각하세요.
  - PC에서는 키보드 숫자로도 입력, Esc는 취소
- 방 설정 10가지 (마지막으로 고른 값을 이 기기에 기억)
  | 항목 | 고를 수 있는 값 |
  |---|---|
  | 게임 시간 | 5 / 8 / 10분 |
  | 목표 점수 | 20 / 30 / 40점 |
  | 문제 난이도 | 쉬움 / 보통 / 어려움 |
  | 수학 미션 수 | 한 학생당 3~6문제 |
  | 팀 크기 | 2 대 2 ~ 5 대 5 (넘치는 학생은 그 경기 관전) |
  | 같은 캐릭터 | 여러 명 가능 / 팀마다 한 명 |
  | 특수기 | 사용 / 사용 안 함 |
  | 재등장 시간 | 3 / 5 / 7초 |
  | 선생님 | 관전(TV 화면) / 함께 참가 |
  | 빈자리 채우기 | 봇으로 인원 맞춤 / 채우지 않음 |
- 교사용 대기방
  - 방 번호 4자리 (학생은 시작 화면에서 이 번호로 입장 — 실제 연결은 STEP 16)
  - 설정 한 줄 요약 + [설정 바꾸기] (방 안에서는 PIN 다시 묻지 않음)
  - 새 학생은 인원이 적은 팀으로 자동 배정, [팀 섞기]로 다시 반반, 이름을 누르면 반대 팀으로 옮김
  - 팀 크기를 넘는 학생에게는 "관전" 표시, 빈자리는 "+ 봇 N명" 미리 보기
  - 학생이 없으면 시작 버튼이 "학생을 기다리는 중"으로 잠김
  - [방 닫기]는 실수 방지를 위해 두 번 눌러야 닫힘
  - 경기가 끝나고 [대기방으로]를 누르면 같은 방 번호, 같은 팀으로 돌아옴
- 선생님 관전: 캐릭터 고르기 대신 안내가 나오고, 경기에서는 전체 화면 관전
- 선생님 참가: 선생님도 캐릭터를 고르고 한 팀에 꼭 들어감
  - 학생 9명 + 선생님 참가 → 5 대 5 (봇 없음)
  - 학생 9명 + 선생님 관전 → 5 대 4 + 봇 1 (봇은 STEP 21부터 존을 지키고 공격함)
- **[+ 시험 학생]** 은 가상의 학생을 넣어 보는 시험용 버튼입니다. (STEP 16부터는 인터넷이 안 될 때나 `?test=1`일 때만 보임)

## STEP 14 (대기방)

화면 흐름: **시작 화면 → 대기방 → 3·2·1 → 경기 → 결과 → [대기방으로]**
- 시작 화면: 닉네임(8글자까지), 방 번호(숫자 4자리), [참가하기], [혼자 연습하기], 오른쪽 위 [교사용]
  - 닉네임은 이 기기에 기억됨. 입력 칸에서는 W·A·S·D·H·F 같은 글자도 게임 조작 없이 그대로 입력됨
  - [참가하기]로 친구들과 같은 방에 모이는 것은 STEP 16(멀티플레이), [교사용]은 STEP 15에서 연결
- 대기방: 방 번호, 참가 인원, SOLAR·LUNAR 팀 목록(닉네임·캐릭터·"나"/선생님/봇 표시)
  - 캐릭터 6종 카드 + 능력치 막대(체력·속도·사거리·공격) + 기본 공격·특수기 설명 + 반지름별 비용
  - 시작 버튼은 방장(교사)만. 학생은 "선생님이 게임을 시작하기를 기다리는 중…"
  - "캐릭터 중복 허용"이 꺼져 있으면 같은 팀이 고른 캐릭터는 고를 수 없음
- 시작하면 3·2·1 카운트다운 (그동안 움직일 수 없음)
- 경기가 끝나면 [대기방으로] → 새로고침 없이 다음 경기 (점수·에너지·미션 수 모두 처음부터)
- 테스트 도구(캐릭터 바꾸기, 나에게 -30, ⚡ 가득)와 연습 상대는 "혼자 연습"에서만 나옴
- 개발 시험용: 주소 끝에 `?play=1`을 붙이면 시작 화면 없이 바로 혼자 연습 경기
  (`?view=spectate`, `?quick=1`도 바로 시작)

## STEP 13 (게임 보상 연결)

| 결과 | 에너지 | 보너스 |
|---|---|---|
| 힌트 없이 정답 | ⚡ +20 | 하나 고르기 |
| 힌트를 보고 정답 | ⚡ +12 | 하나 고르기 |
| 정답과 풀이를 봄 | ⚡ +5 (참여 보상) | 없음 |

- 보너스 (정답이면 미션 창 안에서 고르기, PC는 1·2·3 키, 6초 안에 안 고르면 탄약 자동)
  - 탄약 즉시 충전: ● ● ● 가득
  - 5초 보호막: 5초 동안 피해 40까지 막음 (하늘색 거품, 남은 양만큼 두껍게)
  - 3초 가속: 이동속도 35% 빠르게 (뒤쪽에 초록 줄무늬)
- 에너지는 최대 60을 넘지 않음 ("⚡ +20 (최대 60)" 안내)
- 체력이 0이 되면 보너스 효과는 사라짐. 보너스를 고르는 중에 재충전되면 정답과 에너지는 인정, 보너스만 없음
- 수학을 잘하는 학생만 너무 강해지지 않게: 한 경기 최대 5문제, 75초 쿨다운, 에너지 상한 60, 보너스는 짧고 하나만
- 스펙의 "에너지 존 활성화" 보상은 너무 강해서 넣지 않음
- 값은 config.js의 ENERGY.MISSION_*, MISSION.REWARDS / SHIELD_* / SPEED_* 에서 조절

## STEP 12 (원의 넓이 문제 시스템)

- 문제은행 55문제 (`js/questions.js`, 전체 목록은 `문제은행_목록.md`)
  | 유형 | 문제 수 | 난이도 | 분류 |
  |---|---|---|---|
  | TYPE 1 반지름으로 넓이 (+ 원주율 개념 2, 넓이→반지름 3) | 15 | 쉬움 12 / 어려움 3 | 원의 넓이 |
  | TYPE 2 지름으로 넓이 | 8 | 보통 | 원의 넓이 |
  | TYPE 3 반지름 ↔ 지름 | 8 | 쉬움 | 반지름·지름 |
  | TYPE 4 두 원 비교 (A / B / 같다 고르기) | 8 | 보통 | 넓이 비교 |
  | TYPE 5 넓이가 몇 배 | 8 | 어려움 | 넓이 비교 |
  | TYPE 6 게임 상황 | 8 | 어려움 | 원의 넓이 |
- 게임 중 만드는 상황 문제: "방금 쓴 원형 보호막의 반지름은 3m였어요. 그 원의 넓이는?",
  "…반지름을 6m로 늘리면 넓이는 몇 배?", "우리 팀이 점령한 B존의 지름은 8m. 넓이는?"
- 교사 설정 난이도(config.js difficulty, 시험용 `?diff=easy|normal|hard`)
  - 쉬움: 쉬움 문제만 / 보통: 쉬움 30% + 보통 70% / 어려움: 보통 30% + 어려움 70%
- 한 경기에서 같은 문제는 다시 나오지 않음
- 오답 처리 (정답을 바로 보여주지 않음)
  - 숫자 문제: 1번째 "다시 계산해보세요." → 2번째 힌트 → 3번째 정답과 풀이 (틀림으로 기록)
  - 고르기 문제: 1번째 "다시 생각해보세요"(고른 버튼은 흐려짐) → 2번째 힌트 → 남은 보기에서 다시 고르기 (STEP 21에서 기획서 39번대로 바꿈)
  - 닫았다 다시 열어도 힌트·흐려진 버튼·틀린 횟수가 그대로
- 고르기 문제는 숫자 패드 대신 큰 버튼 3개 (PC는 1·2·3 키)
- 미션 창 위쪽에 난이도(쉬움·보통·어려움) 표시
- 기록: 문제 번호, 유형, 분류(원의 넓이/반지름·지름/넓이 비교), 난이도, 정답 여부, 틀린 횟수, 힌트 봤는지, 걸린 시간

## STEP 11 (수학 터미널)

- 우리 팀 쪽 에너지 터미널(각 팀 2개) 사용 거리 2m 안에 들어가면
  - 터미널에 밝은 고리와 "수학 미션" 표시, 화면 아래 가운데 [수학 미션] 버튼
  - PC는 F 키, 태블릿은 버튼을 눌러 시작
  - 상대 팀 쪽 터미널은 쓸 수 없음 (config.js MISSION.OWN_SIDE_ONLY)
- 미션 창: 문제를 크게 보여주고 숫자 패드(태블릿) 또는 키보드 숫자·. ·Backspace·Enter(PC)로 입력
  - 미션 창이 열려 있으면 키보드는 답 입력에만 쓰임 (숫자키가 캐릭터를 바꾸지 않음)
  - 오답: "다시 계산해보세요." (두 번째 오답 힌트는 STEP 12)
  - 정답: "정답!" → 창이 닫히고 "미션 성공! 3 × 3 × 3.14 = 28.26" 안내
  - [닫기]/Esc: 풀지 않고 나가면 다음에 같은 문제가 그대로 나옴 (문제 바꾸기 방지)
- 문제를 푸는 동안: 캐릭터는 제자리, 받는 피해 절반, 머리 위에 "문제 푸는 중"
  - 재충전(체력 0)되거나 경기가 끝나면 창이 닫힘 (문제는 다음에 다시)
- 한 문제를 끝내면 개인 쿨다운 75초 (버튼에 남은 시간 표시)
- 한 경기 최대 5문제 (교사 설정 missionLimit). 다 풀면 "미션 완료"
- 푼 문제 기록(정답 여부, 틀린 횟수, 걸린 시간)을 모음 → STEP 19 학습 결과
- `?quick=1`이면 미션 쿨다운 10초

## STEP 10 (원형 범위 시스템)

반지름에 따라 넓이가 얼마나 달라지는지 게임 화면에서 바로 비교하게 합니다.
- 반지름을 바꾸면(r 버튼, R 키) 오른쪽에 비교 카드가 3초 동안 나타남
  - 예) 반지름 2m → 4m (2배) / 넓이 12.56㎡ → 50.24㎡ / 넓이 비 1 : 4 → 4배
  - 3m → 4m: 넓이 비 9 : 16 → 약 1.8배 / 2m → 3m: 4 : 9 → 2.25배 / 4m → 2m: 1/4배
- 특수기 미리보기에 고를 수 있는 r2·r3·r4 원을 점선으로 겹쳐 그림
  방금 바꾼 이전 원은 1.5초 동안 진하게 → 크기 차이가 한눈에
- 에너지 바: 미리보기 중에 이번에 쓸 만큼이 흰색으로 깜빡임 (모자라면 빨간색)
- 반지름 버튼 안의 작은 원도 지름이 반지름에 비례 (10px · 15px · 20px)
- 원을 놓으면 1.5초 동안 "r3 · 28.26㎡" 라벨
- 설계서의 "범위 업그레이드 LEVEL 1·2·3" = r2·r3·r4 선택

## STEP 9 (6개 캐릭터 특수기 + 원형 범위 선택)

에너지(⚡)로 특수기를 씁니다. **비용 = 고른 원의 넓이(반올림)**
| 반지름 | 넓이 | 비용 |
|---|---|---|
| 2m | 12.56㎡ | 13⚡ |
| 3m | 28.26㎡ | 28⚡ |
| 4m | 50.24㎡ | 50⚡ |

- 에너지 얻기: 기본 공격 적중 +3, 존 안에 있으면 초당 +1, 재등장 +10 (최대 60)
- 에너지 바 눈금 r2·r3·r4 = 각 원의 넓이 위치. 쓸 수 있는 눈금은 밝게 빛남
- 특수기 6종 ("원 안" = 캐릭터 중심이 원 안, 에너지 존과 같은 기준)
  - 블래스터 에너지 폭발: 12m 안에 던짐 → 0.5초 뒤 원 안 상대에게 30 (벽 뒤는 안전)
  - 가디언 원형 보호막: 내 자리, 5초 동안 원 밖에서 오는 탄·충격파·폭발을 막음
  - 메딕 원형 회복존: 9m 안, 6초 동안 매초 원 안 우리 팀 +8
  - 스피더 순간이동: 반지름 6m 원 안 어디로든 (20⚡ 고정, 벽 안이면 가까운 빈 곳)
  - 엔지니어 원형 범위 터렛: 6m 안, 20초 동안 원 안 상대를 1초마다 자동 공격(8)
  - 프로스트 원형 둔화지역: 10m 안, 5초 동안 원 안 상대 이동속도 40% 감소
- 조작
  - PC: E 키(또는 마우스 오른쪽 버튼)를 누르고 있으면 미리보기 → 떼면 사용. Esc 취소. R 키로 반지름 바꾸기
  - 태블릿: [특수기] 버튼을 누른 채 끌어서 원 놓을 곳 정하고 떼기. 톡 누르면 내 자리(블래스터는 가까운 상대)
  - 오른쪽 아래 r2·r3·r4 버튼으로 반지름 선택 (PC·태블릿 모두)
- 미리보기: 원, 반지름 선, "r 3m", "28.26㎡ · 28⚡". 에너지가 모자라면 빨간 원 + "부족"
- 에너지가 모자란데 쓰면: "반지름 3m 원의 넓이 28.26㎡ → 28⚡ 필요" 안내
- 테스트: G 키 또는 [⚡ 가득] 버튼으로 에너지 채우기
- 교사 설정의 "특수기 사용 여부"(config.js specialsEnabled)를 끄면 특수기·에너지 바가 사라짐

## STEP 8 (점령과 팀 점수)

- 한 팀만 존 안에 있으면 점령 게이지가 차오름. 다 채워야 하는 양 = 존의 넓이(㎡)
  - 1명 기준: A존 약 9초, B존 약 17초, C존 약 26초 (2명 4.5㎡/초, 3명 5.5, 4명 이상 6)
  - 게이지는 안쪽 원의 "넓이"로 표시 → 50%일 때 안쪽 원 반지름은 약 0.71배
  - 존 안에 "39.2 / 78.5㎡" 처럼 채운 넓이 표시
- 두 팀이 함께 있으면 게이지 멈춤 (대치 중)
- 상대가 점령한 존: 상대 게이지를 0까지 깎아 중립 → 우리 팀 게이지를 채워 탈환
- 아무도 없으면 게이지가 초당 2㎡씩 제자리로 (주인 없는 존은 0으로, 점령된 존은 가득으로)
- 점령한 존: 테두리가 팀 색 실선, 바깥 흰 고리가 다음 점수까지 남은 시간
- 15초마다 A·B +1점, C +2점
- 승리: 목표 점수(기본 30) 먼저 달성, 또는 시간(기본 8분) 끝났을 때 점수가 높은 팀
- 동점이면 1분 연장전: A·B는 쉬고, C존을 먼저 점령한 팀이 승리. 그래도 안 나면 무승부
- 마지막 30초와 연장전에는 시간 표시가 빨갛게 깜빡임
- LUNAR 플레이어 화면에서는 우리 팀(LUNAR) 점수가 왼쪽
- 점령 기여도(게이지를 민 넓이 ㎡)를 개인 기록으로 모음 (결과 화면은 STEP 19)
- 빠른 시험: 주소 끝에 `?quick=1` → 1분 경기, 목표 10점, 5초마다 점수

## STEP 7 (에너지 존)

- 캐릭터 중심이 원 안(중심까지 거리 ≤ 반지름)에 있으면 "존 안"으로 판정
- 한 팀만 있으면 존이 그 팀 색으로 물들고, 두 팀이 함께 있으면 흰색으로 깜빡이며 "대치 중"
- 존 아래쪽에 팀별 인원 배지 (● 2  ● 1)
- 재충전 중인 캐릭터는 세지 않음
- 내 캐릭터가 존에 들어가면 위쪽에 넓이 구하는 식이 2.5초 동안 나타남
  예) C존에 들어왔어요 / 반지름 5m → 5 × 5 × 3.14 = 78.5㎡
- 화면 아래에 탄약·에너지 표시 자리를 따로 비워 맵을 가리지 않게 함

## STEP 6 (체력과 재등장)

- 캐릭터 위 체력바 (팀 색, 30% 이하면 빨강, 방금 깎인 부분은 흰색으로 천천히 줄어듦)
- 체력 0 → 에너지 조각이 흩어지며 사라짐 → 화면에 "에너지 충전 중 / 재충전 중... 5"
- 재등장 시간(기본 5초, config.js의 respawnSeconds) 뒤 자기 팀 시작 지역에서 체력·탄약 가득 채워 등장
- 재등장 직후 1.5초 보호 (맞아도 "보호" 표시, 피해 없음). config.js의 RESPAWN.PROTECT_SEC
- 충전 중에는 맞지 않고, 움직이거나 쏠 수 없음. 자동 조준도 충전 중인 상대는 건너뜀
- 테스트: H 키 또는 [나에게 -30] 버튼으로 내 캐릭터 재충전 시험

## STEP 5 (발사체 충돌)

- 탄이 벽·상자·기둥·터미널·경기장 테두리에 막힘 (부딪힌 자리에 불꽃)
- 상대 팀을 맞히면 탄이 사라지고, 맞은 캐릭터가 하얗게 반짝이며 피해 숫자가 떠오름
- 같은 팀과 쏜 사람 자신은 통과
- 가디언 충격파: 부채꼴 안의 상대를 한 명당 한 번만 맞히고, 벽 뒤는 맞히지 않음
- LUNAR 팀 "연습 상대" 4명이 서 있습니다 (2명은 위아래로 움직임, 1명은 상자 뒤). 멀티플레이를 연결하면 없앱니다.

## STEP 4 (조준과 기본 공격)

- `index.html`을 더블클릭하면 바로 열립니다. (서버 필요 없음)
- 벽·상자·기둥·터미널에 막히고, 비스듬히 부딪히면 벽을 따라 미끄러집니다.
- PC: 마우스로 조준, 왼쪽 클릭 또는 스페이스바로 발사
- 태블릿: 오른쪽 아래 공격 조이스틱
  - 끌어서 조준 → 손을 떼면 발사 (조준선이 사거리까지 보임)
  - 톡 누르기 → 사거리 안 가장 가까운 상대에게 자동 조준 (상대가 없으면 바라보는 방향)
  - 끌었다가 가운데로 되돌려 떼기 → 발사 취소
- 탄약 3발, 캐릭터마다 1발 충전 시간이 다름. 탄약이 없는데 쏘면 탄약 표시가 흔들림
- PC: WASD 또는 방향키로 이동. 한글 입력 상태여도 움직입니다.
- 태블릿: 화면 왼쪽 아래를 누르면 그 자리에 조이스틱이 나타납니다.
- 숫자키 1~6 또는 화면 아래 [테스트] 버튼으로 캐릭터를 바꿔 속도를 비교할 수 있습니다. (대기방이 생기면 없앱니다)
- 주소 끝에 붙이는 테스트 옵션
  - `?view=spectate` : 교사 관전 화면 (조작 없음)
  - `?touch=1` : PC에서 마우스로 조이스틱 시험
  - `?debug=1` : 충돌 상자(빨강)와 캐릭터 몸(초록) 보기
  - 여러 개를 함께 쓸 때는 `&`로 잇습니다. 예: `?touch=1&debug=1`

## 교사 참가 / 관전

방 설정 화면의 "선생님" 항목에서 고릅니다. (처음 기본값은 `config.js`의 `ROOM_DEFAULTS.teacherRole`)

| 설정 | 학생 9명일 때 | 교사 화면 |
|---|---|---|
| `'play'` (참가) | 교사 포함 5 대 5, 봇 없음 | 플레이 화면 + 호스트 역할 |
| `'spectate'` (관전) | 5 대 4 + 봇 1 = 5 대 5 | 전체 경기 관전 (TV 띄우기용) |

- 교사가 참가하면 인원이 꽉 차도 교사 자리는 꼭 확보됩니다.
- 결석생이 있으면 인원이 적은 팀에 봇이 자동으로 들어갑니다.
