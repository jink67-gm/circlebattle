# 서클배틀

초등학교 6학년 「원의 넓이」 × 실시간 팀 대전 웹게임

## 완성 — STEP 21 전체 테스트 + 게임 개선 4단계 + PNG 캐릭터 + 궁극기·사운드까지 끝남

### 수업에서 쓰는 순서
1. **선생님 기기(TV 연결)**: [교사용] → PIN → 방 설정 → [방 만들기] → **[🔗 학생 초대 링크 복사]** 로 링크를 보내거나 화면의 **방 번호 4자리**를 알려 주기
2. **학생 태블릿**: 초대 링크를 열면 방 번호가 이미 들어 있음 → 닉네임만 쓰고 [참가하기] (링크 없이 방 번호를 직접 써도 됨) → 캐릭터 고르기
3. 선생님: 팀 확인(이름 누르면 옮기기, [팀 섞기]) → **[게임 시작]**
4. 경기 후: 결과 화면 → **[📊 학습 결과 보기]** → 필요하면 CSV 내려받기 → [대기방으로] → 다음 경기
- 인터넷이 없어도 학생 각자 [혼자 연습하기]는 됩니다.

### 게임 개선 (4단계) — 모두 끝남
목표: "전체 맵이 한눈에 보이는 교육용 게임" → "넓은 맵을 탐색하고, 부쉬에 숨어 기습하고, 스킬로 싸우고, 수학으로 성장하는 팀 아레나 게임".
수학 흐름(버티기 → 점령 문제 → 활성화 → 점령, 터미널 LEVEL 1~3 → TEAM BOOST, 원주율 안내, "반지름 3m")은 그대로입니다.

**새 STEP 1 · 현재 구조와 모든 캐릭터 분석** (끝남) — 분석 결과는 대화에 정리

**새 STEP 2 · 캐릭터 추적 카메라 + 넓은 경기장 + 부쉬** (끝남)
- **추적 카메라**: 학생마다 자기 캐릭터를 따라감 (기기마다 따로). 부드럽게 따라가되 0.7초 안에 따라붙고, 재등장처럼 멀리 옮겨지면 바로.
  상대 쪽을 2.5m 더 보여 줌. 화면 세로에 약 22m (휴대폰 가로 화면은 가로 40m까지) → 캐릭터가 예전보다 약 2배 크게 보임.
  경기장 밖은 테두리만 보임. 마우스 조준·스킬 위치도 카메라에 맞게 계산
- **HUD 고정**: 점수·시간·체력·탄약·스킬 카드·TEAM BOOST 띠는 화면에 그대로. 오른쪽 위에 **미니맵** (존 주인 색, 우리 팀 점, 보이는 상대만, 내 화면 범위)
- **선생님 관전(TV)**: 지금처럼 경기장 전체. "함께 참가"면 학생과 같은 추적 카메라
- **경기장 76m × 48m** (예전 48m × 30m의 약 1.6배). SOLAR 왼쪽 / LUNAR 오른쪽 시작 (가로 화면·TV에서 앞이 넓게 보임), 두 팀에게 완전히 공평한 대칭
  - 점령지역은 가운데 세로선 위에: **A 위쪽 레인(반지름 3m, +1점) · B 가운데 핵심(반지름 5m, +2점) · C 아래쪽 레인(반지름 4m, +1점)**.
    존 사이 간격 6~7m (예전 1~2m). **연장전은 가운데 B존**
  - 위·가운데·아래 3개 레인, 맵 위·아래 가장자리 **우회로**, 레인 사이 벽 틈 **좁은 통로**, B 주변 **넓은 교전 공간**, 상자·기둥·방벽 엄폐물
  - 에너지 터미널 3종류: **뒤쪽 모서리**(우리 팀만 · 안전하지만 존까지 멂) · **가운데 공용**(A–B 사이, B–C 사이 · 두 팀 모두 · 빠르지만 상대와 만나기 쉬움).
    상대 팀 뒤쪽 터미널은 화면에 표시하지 않음
- **부쉬(수풀) 16곳**: A 옆 우회로 출구, B로 들어가는 측면 길, 위·아래 레인 상자 뒤, 뒤쪽 터미널 가는 길 (존과 터미널은 덮지 않음)
  - 상대가 부쉬 안에 있으면 **안 보임**, 우리 팀은 계속 보임(반투명). 내 캐릭터 발밑에 "🌿 숨음" / "드러남!"
  - **같은 부쉬 안**이거나 **2.5m 안까지 다가오면** 보임 (우리 팀 한 명이 보면 팀 전체 화면에 보임)
  - 부쉬 안에서 **쏘거나 스킬을 쓰면 1.2초, 맞으면 0.9초** 드러남. 부쉬 밖으로 나오면 바로 보임
  - 숨은 상대도 **탄·폭발·냉기·터렛은 그대로 맞음**. 스페이스 자동 조준과 봇은 숨은 상대를 고르지 않음
  - 이름·체력바·"느려짐"·머리 위 효과(회복 숫자·TEAM BOOST·레벨업)·미니맵 점으로 위치가 새지 않게 함
  - **교실 TV에서도 숨김** (학생들이 TV를 보고 숨은 상대를 찾지 못하게). 상대 팀에게 드러나면 TV에도 보임
  - 멀티플레이: 캐릭터를 지우지 않고 기기마다 "그릴지"만 정함 (`inBush` · `bushZoneId` · `revealedUntil`). 드러난 시간은 교사 기기가 정해 보냄
- **빈자리 봇**: 넓은 경기장의 긴 벽을 돌아가도록 길 찾기 (벽 모서리 길목을 잇는 가장 짧은 길)
- **성능**: 경기장 전체를 경기 시작 때(3·2·1 동안) 그림 한 장으로 미리 그려 두고(1m = 최대 60픽셀), 뒤쪽 맵 캔버스는 화면보다 20% 넓게 한 번 붙여 둔 뒤
  카메라가 움직이면 통째로 밀기만 함(GPU). 화면 밖 캐릭터·탄·효과·부쉬는 그리지 않고, 부쉬 그림은 한 번만 만듦. 빛 번짐은 흐림 효과 대신 가벼운 선·그라디언트로
  - 시험(아이패드 해상도, 캐릭터 10명·스킬 원 여러 개, 소프트웨어 그리기): 초당 47~54장 (예전 전체 맵 57~59장), 멀리 순간이동·재등장해도 멈칫 없음(0.08초 안)
- 혼자 연습: 연습 상대 5명 (1 가디언이 B존을 가로질러 걸음, 5 스피더는 오른쪽 부쉬 안 — 가까이 가거나 맞히면 보임)
- 문제은행: 가운데 존이 B로 바뀌어 "C존의 반지름은 5m" 문제 1개를 "B존"으로 고침 (점령 문제는 맵에서 자동으로 만들어져 그대로 맞음)
- 고친 오류: 수정 STEP 6의 "점령 문제 고르기형 첫 오답 → 다시 계산해보세요." 가 실제로는 적용되지 않던 것을 바로잡음

**새 STEP 3 · 맵 비주얼 + 모든 캐릭터·스킬 + 화면 표시** (끝남)
- **미래형 에너지 경기장** (`js/arena.js`, 경기 시작 때 그림 한 장으로 — 매 프레임 부담 없음)

  - 가운데 경기선과 B 둘레 큰 경기장 원(눈금) · 가장자리 우회로는 철망 바닥 · 바닥 환기구 · 시작 지역 앞 길 안내(→ A / → B / → C)와 존 쪽 화살표

  - 조명(존·터미널·시작 지역·발전장치 둘레 밝게) + 가장자리 어둡게 + 테두리 조명. **그림은 충돌 사각형 안에만** (그림자만 바깥) → 보이는 것과 막히는 것이 같음
- **부쉬**: 수풀·관목·풀잎·빛나는 에너지 식물 뭉치 그대로. 누가 **들어가면 그 부쉬 전체가 0.45초 살짝 흔들림** (부쉬 전체가 흔들려서 정확한 자리는 알 수 없음)
- **존 = 에너지 기지**: 금속 발판 + 발광 장치 8개
  - 중립 회색·흰색 / SOLAR 노랑·주황 / LUNAR 파랑·보라
  - 점령 준비: 존 둘레 게이지(팀마다 가장 오래 버틴 친구 기준, 발밑 고리도 그대로) · 정답: 빛 고리 + **"ZONE ACTIVATED!"** · 활성화된 팀 색으로 발광 장치 깜빡임
  - 점령 중: 팀 색 고리 3조각이 돎(인원이 많을수록 빠르게), 게이지는 예전처럼 **넓이만큼 차는 안쪽 원** · 대치 중: 흰 고리 깜빡임
  - 점령 완료: 겹겹이 퍼지는 물결 + "CAPTURED!", 이후 팀 색 빛·물결·올라가는 빛 알갱이

- **캐릭터·스킬 개선** (새 STEP 1 분석 결과 반영)

- **스킬 효과 그림** — LEVEL 2는 더 크고, **LEVEL 3 MAX는 금색**으로 화려하게
  - 블래스터: 위험 눈금·모여드는 불꽃 → 섬광·충격파 고리(LEVEL 2 두 겹, MAX 금색 별빛)·파편, 밀려난 상대에 밀린 방향·거리 화살표
  - 가디언: 반투명 벌집 무늬 보호막, 맞으면 테두리를 따라 물결, 막는 양이 줄면 테두리가 얇아지고 금이 가고 깜빡이다 조각나며 깨짐, MAX는 둘레에 도는 금색 방패
  - 메딕: 초록 빛 + 1초마다 퍼지는 회복 파동(회복 박자와 같음) + 올라가는 + 알갱이, MAX는 가운데 금빛 십자
  - 스피더: 출발점 → 도착점 빛 줄기와 흐린 잔상, MAX 가속 중에는 금빛 줄기
  - 엔지니어: 기계 터렛(포신 1·2·3개), 에너지 선, 체력 막대, 맞으면 번쩍, 부서지면 금속 조각·연기, MAX 레이더
  - 프로스트: 서리 바닥·얼음 금·내리는 눈·얼음 결정 기둥(LEVEL 2 8개, MAX 12개 + 서리 안개)
- **화면 표시(HUD)** — 긴 글 대신 아이콘 + 숫자 + 막대
  - 위: 비스듬한 팀 판(해·달 아이콘, 큰 점수, **목표 점수까지 막대**) · 가운데 시간 + **존 주인 A·B·C** (팀 색 / 점선 = 활성화됨 / 깜빡 = 대치 중)
  - 아래: 내 캐릭터 그림 + **♥ 체력 막대와 숫자**(30% 이하 빨강 깜빡임) · 탄약 ● ● ● · ⚡ 에너지 막대
  - 오른쪽: **동그란 특수기 버튼**(캐릭터 문양 + 이름 + 비용, **둘레 고리 = 한 번 쓸 에너지를 얼마나 모았는지**, MAX는 금색) · 스킬 칩 "●●○ LEVEL 2 · ◎ 반지름 3m"
- **멀티플레이**: 판정은 모두 교사 기기. 밀어내기는 교사 기기가 밀린 학생 기기에 알려서 그 기기가 직접 밀어냄(다른 기기도 같은 자리),
  보호막 막는 양·터렛 체력·스피더 가속·얼음탄 둔화는 경기 상황에 실어 보냄. 밀린 화살표·회복 빛·순간이동 잔상처럼 캐릭터에 붙은 효과는 그 캐릭터가 부쉬에 숨어 있으면 상대 화면에 안 그림
- **성능**: 원의 움직이지 않는 부분(그라디언트·벌집 무늬·얼음 금·결정)은 한 장으로 만들어 붙이기만 함, 몸 색 그라디언트 재사용, 흐림 효과 없음.

### 궁극기 + 사운드 (BGM·효과음) — 끝남
캐릭터 = **기본 공격 + 고유 스킬(LEVEL 1) + 궁극기(LEVEL 2)**. 새 기술은 "스킬 2"가 아니라 궁극기입니다.

**에너지 터미널 성장**
| 정답 | 바뀌는 것 |
|---|---|
| 1번째 | **LEVEL 1** — 고유 스킬 해금 |
| 2번째 | **LEVEL 2** — 궁극기 해금 · 게이지가 차기 시작 (0%부터) |
| 3번째 | **LEVEL 3 MAX** — 고유 스킬 + 궁극기 강화 |
| 그 뒤 | TEAM BOOST (예전 그대로) |
문제 창 위쪽 안내도 "정답이면 LEVEL 2 · 궁극기 해금"처럼 바뀝니다. 고유 스킬 원의 반지름(원의 넓이 연결)은 예전처럼 LEVEL마다 커집니다.

### PNG 캐릭터 적용 — 끝남
새 캐릭터 그림 6장(`assets/characters/blaster.png` · `guardian.png` · `medic.png` · `speeder.png` · `engineer.png` · `frost.png`)을 게임에 넣음.
이동·체력·탄·스킬·점령·터미널·팀전·멀티플레이 코드는 그대로이고, 캐릭터를 그리는 부분과 연결 부분만 바꿈.

- **그리는 방식** (`js/character.js`): `CharacterRenderer.draw()` → 캐릭터 그림을 불러왔으면 `drawSprite`, 못 불러왔으면(파일 없음·오류) 예전 도형 캐릭터 `drawLegacyCharacter` (fallback — 지우지 않고 남겨 둠).
  대기방 그림도 같음. 그림은 화면 배율에 맞춰 처음 한 번만 줄여 두고 붙이기만 함 (태블릿 성능)
- **그림 손질**: 원본(1254px)에서 그림자 번짐을 빼고(게임이 발밑 그림자·팀 고리를 직접 그림) 높이 400px로 줄임 (한 장 120~160KB)
- **선택 화면과 경기 화면 크기 따로**: 캐릭터 선택 카드는 그림이 칸을 거의 다 채우게 크게(112px, `SELECTION_FILL`),
  경기에서는 높이 약 1.8m(`GAMEPLAY_SCALE` — 상자 1.2~1.6m, 통로 3m 이상이라 맵을 가리지 않음)
- **그림 크기 ≠ 충돌 판정**: 충돌 반지름 0.7m·사거리·탄이 출발하는 자리(판정)는 그대로. 머리 위로 1m 떨어져 지나가는 탄은 그림에 닿아 보여도 안 맞음
- **발 위치·무기 위치** (캐릭터마다 `foot` · `muzzle`): 발이 발밑 팀 고리 가운데에 닿게 맞춤(공중에 떠 보이지 않게).
  쏘면 무기 끝에 총구 불꽃이 나고, 탄은 무기 끝에서 보이기 시작해 1.4m 안에 원래 길로 이어짐 (그리는 자리만 옮김)
- **방향**: 그림은 오른쪽을 봄 → 왼쪽을 조준하면 좌우 반전, 위·아래를 조준하면 아주 조금(최대 약 6°) 기울임. 숨쉬기·통통 걷기·쏠 때 반동·맞으면 흔들림+하얗게 번쩍·스킬 동작은 그대로
- **팀 구분**: 캐릭터 색은 팀과 상관없이 그대로(블래스터 빨강·가디언 금색·메딕 민트·스피더 보라·엔지니어 보라 기계·프로스트 파랑). **발밑 고리**(SOLAR 주황 / LUNAR 하늘색)로 구분 — 고리는 캐릭터 아래에
- **LEVEL**: 같은 그림 + LEVEL 2 약한 외곽 빛, LEVEL 3 MAX 금빛 외곽 + 발밑 금빛 고리, MAX 가 되는 순간 금빛 번쩍과 퍼지는 고리 (작게, 화면이 지저분하지 않게)
- **캐릭터 선택 카드**: 큰 그림 + 한 줄 특징 — 블래스터 "강한 3발 공격" · 가디언 "튼튼한 방어형" · 메딕 "약하지만 많이 쏘는 지원형" · 스피더 "빠른 기동형" ·
  엔지니어 "장치 설치 전략형" · 프로스트 "상대를 느리게 만드는 제어형". 설명 칸에 **탄약** 막대와 LEVEL 1·2·3 MAX 미리 보기

- **얼굴이 보이는 2등신 캐릭터**: 위에서 내려다본 "도는 판" 대신, 몸은 똑바로 서 있고 **무기를 든 팔만 조준 방향으로** 돎. 왼쪽을 보면 좌우가 뒤집힘.
  위쪽을 조준하면 무기가 몸 뒤로 감. 눈동자도 조준 방향을 봄
- **공통 스타일**: 머리·몸통·장비 구분, 두꺼운 어두운 외곽선, 왼쪽 위 하이라이트와 입체 그늘, 발밑 그림자.
  **팀은 발밑 고리 색 + 허리띠 색**(이름·체력바도 팀 색), 고리 위 작은 화살표 = 조준 방향, 내 캐릭터는 흰 점선 고리
- **캐릭터별 모양** (색 = 역할)

  | 캐릭터 | 색 | 모양 | 표정 |

  - 가만히: 숨쉬기 · 걸을 때: 통통 튀고 발이 번갈아 움직이며 가는 쪽으로 살짝 기울어짐 (스피더는 늘 앞으로 기운 자세, 빨리 달리면 잔상)
  - 쏠 때: 무기 반동 + 몸이 살짝 눌림 + 총구 불꽃 (가디언은 방패로 밀어냄)

**수정 STEP 2 · 점령지역 + 수학 문제** (끝남)
- 점령 순서: 존에 들어감 → **3초 버티기**(밖으로 나가면 처음부터, 버티는 동안은 평소처럼 싸움)

- 제한 시간 30초. 1번째 오답 "다시 계산해보세요" → 2번째 힌트 → 3번째(또는 시간 끝) 도전 실패 → 5초 뒤 다시

5. 처음 한 번 "홈 화면에 추가" 해 두면 다음부터 아이콘으로 바로 실행

## STEP 19 (학습 결과)

- 멀티플레이: 기록은 교사 기기가 계산해서 학생 기기로 보냅니다.
  (받지 못하면 4초 뒤 내 기기의 수학 기록만이라도 보여줌)
- 관전하는 선생님 화면(TV): 개인 기록 대신 **우리 반 수학 미션** (팀별 정답 수, 전체 정답률)

### 교사용 학습 결과 (교사 기기에만)
열기: 경기 결과 화면의 **[📊 학습 결과 보기]**, 또는 교사 대기방의 **[📊 학습 결과]**
- **이번 경기 / 오늘 전체** (같은 기기 = 같은 학생으로 합쳐서, 몇 경기 했는지 표시)

- **다시 짚어 볼 문제**: 두 명 이상 푼 문제 중 정답률이 낮은 문제 (문제와 정답)

  - **[학생별 표 가리기 (TV용)]**: TV에 띄울 때는 반 전체 요약만

- 혼자 연습은 저장하지 않습니다. (학생 자기 기기의 연습)

## STEP 18 (환경설정)

게임 화면 오른쪽 위 **⚙ 버튼** (PC는 **Esc** 키)
- **소리 · 화면**
  - 전체 음량 / 배경음 / 효과음 막대 (0~100, 기기마다 기억). 손을 떼면 들어 보기 소리
  - 소리 끄기/켜기 (PC의 M 키와 같음)
  - 전체화면 켜기/끄기 — 안드로이드 태블릿은 전체화면일 때 가로로 고정
    전체화면이 안 되는 기기(아이폰 등)는 "홈 화면에 추가" 안내
- **조작 설명**: 태블릿·PC 조작 (지금 쓰는 기기를 먼저, 휴대폰에서는 그 기기 것만),
  내 캐릭터의 기본 공격·특수기, 규칙 한눈에 보기 (존 넓이·점수, 에너지, 특수기 비용 = 원의 넓이, 승리 조건 — 지금 경기 설정 값으로)
- **나가기** (실수 방지: 두 번 눌러야 나감, 2.5초 지나면 원래대로)

| 누가 | 버튼 | 어떻게 되나요 |
|---|---|---|
| 혼자 연습 | 대기방으로 나가기 | 연습 경기를 끝내고 대기방으로 |
| 학생 기기 | 대기방으로 나가기 | 내 캐릭터는 경기장에서 잠시 빠짐(자리 비움). 대기방의 **[경기로 돌아가기]** 로 다시 들어가면 시작 지역에서 재등장 |
| 선생님 기기 | **경기 끝내기** | 경기가 결과 없이 끝나고 모든 학생 화면이 대기방으로 |
| 경기가 끝난 뒤 | 대기방으로 | 한 번에 대기방으로 |

- 혼자 연습 중에는 설정 창을 여는 동안 **경기가 멈춥니다** (시간·연습 상대·배경음).
- 여러 명이 하는 경기는 멈출 수 없어서 **계속 진행**됩니다. 내 캐릭터는 제자리에 서 있어요.
- 수학 미션을 푸는 중에 열어도 되고, 닫으면 풀던 문제로 돌아갑니다.

### 자리 비움 (멀티플레이)
학생이 경기 중에 나가거나, 태블릿이 잠들거나 와이파이가 끊겨 **6초 넘게 소식이 없으면**
그 학생의 캐릭터는 경기장에서 잠시 빠집니다. (에너지 존을 계속 막고 있거나 과녁이 되지 않게)
다시 연결되면 곧 시작 지역에서 재등장합니다. 시간은 `config.js`의 `NET.AWAY_SEC`.

## STEP 17 (사운드)

> **궁극기·사운드 작업에서 바뀜**: 배경음·효과음은 이제 직접 합성한 mp3 파일(`assets/audio/`)을 씁니다. 자세한 내용은 위 「궁극기 + 사운드」.
> 아래는 STEP 17 당시 설명입니다. (파일을 못 불러올 때 쓰는 "만들어 내는 효과음"은 그대로 남아 있음)

모든 효과음과 배경음은 **소리 파일 없이** 브라우저가 그 자리에서 만들어 냅니다. (직접 만든 원본 소리)
소리는 `js/audio.js`(AudioManager) 한 곳에서 관리합니다.

| 언제 | 소리 |
|---|---|
| 버튼 누르기 / 미션 숫자판 | 짧은 톡 / 더 작은 톡 |
| 공격 | 캐릭터마다 다름 (직선탄 슝 · 엔지니어 구체 뿅 · 가디언 충격파 쉬익) |
| 내 공격이 맞음 / 내가 맞음 | 딱 (명중) / 퍽 (피격) |
| 탄약 한 칸 충전 | 작은 띵 |
| 특수기 | **반지름이 클수록 낮고 긴 소리** (r2 → r3 → r4, 넓이가 커지는 느낌) · 순간이동 · 폭발 |
| 수학 미션 | 열기 · 오답(부드러운 두 음) · 정답(도-미-솔) · 보너스 고르기 |
| 에너지 존 | 점령 시작 · 점령 완료 · 점령 풀림 · 점수 획득 |
| 체력 0 / 재등장 | 에너지가 흩어지는 소리 / 모이는 소리 |
| 시작 | 3 · 2 · 1 · 시작! |
| 경기 끝 | 승리 · 패배 · 무승부 (관전하는 선생님 화면은 축하 소리) |
| 배경음 | 경기 중에만 잔잔한 반복 곡, **연장전에는 빨라짐** |

- 브라우저 규칙 때문에 **화면을 한 번 누른 뒤부터** 소리가 납니다.
- 음량: 전체 / 배경음 / 효과음을 이 기기에 기억합니다. 환경설정(⚙) 화면은 STEP 18.
  처음 값은 `config.js`의 `SOUND.DEFAULT_VOLUME`, 전체 크기는 `SOUND.OUTPUT_GAIN`.
- PC에서 **M 키** = 소리 끄기/켜기 (닉네임 칸에 m을 칠 때는 제외)
- 멀티플레이: 학생 기기도 같은 소리가 납니다. 점령·점수·체력 변화는 각 기기가 화면의 변화를 보고 소리를 내므로 네트워크로 따로 보내지 않습니다.
- 원하는 소리 파일로 바꾸고 싶으면 `config.js`의 `SOUND.FILES`에 적으세요.
  예) `FILES: { correct: 'sounds/correct.mp3', bgm: 'sounds/bgm.mp3' }` — 파일이 없거나 못 불러오면 만들어 내는 소리를 씁니다.
  (파일은 GitHub Pages 주소로 열 때만 불러올 수 있고, index.html을 더블클릭해서 열면 만들어 내는 소리를 씁니다)
- 소리를 지원하지 않는 브라우저에서도 게임은 그대로 됩니다.

## STEP 16 (멀티플레이 — Firebase)

학생 기기들이 교사 방에 들어와 **같은 경기**를 합니다.
- 교사: [교사용] → PIN → 설정 → [방 만들기] → 화면에 나온 **방 번호 4자리**를 알려 주기
- 학생: 닉네임 + 방 번호 → [참가하기] → 캐릭터 고르기 → 선생님이 [게임 시작]을 누르면 모두 함께 3·2·1
- 교사 대기방: 학생이 들어오고 나가고 캐릭터를 바꾸는 것이 바로 보임. 팀 옮기기·팀 섞기는 학생 화면에도 바로 반영
  - 학생 이름 옆 ✕ = 내보내기 (학생 화면은 시작 화면으로, 방 번호로 다시 들어올 수 있음)
  - [방 닫기] → 모든 학생 화면이 시작 화면으로
- 경기가 끝나면 교사가 [대기방으로] → 학생들도 결과를 보고 [대기방으로] → 다음 경기
  (결과를 보고 있던 학생도 선생님이 새 경기를 시작하면 자동으로 들어감)

### 어떻게 맞추나요? (교사 기기가 심판)
- 체력·에너지·명중·점령·점수·시간·특수기는 **교사 기기**가 계산해서 1초에 10번 보냅니다.
- 학생 기기는 **내 캐릭터 움직임만** 직접 계산하고(바로 반응), 위치를 1초에 12번 보냅니다.
- 쏘기·특수기·수학 미션 결과는 "명령"으로 보내고, 교사 기기가 받았다고 할 때까지 다시 보냅니다.
- 그래서 **교사 기기(TV 화면)는 경기 내내 켜 두어야** 합니다. 교사 기기가 잠들면 학생 화면에 "선생님 기기 연결이 끊겼어요"가 뜹니다.

### 연결이 끊겼을 때
| 상황 | 어떻게 되나요 |
|---|---|
| 학생 태블릿 와이파이가 잠깐 끊김 | "인터넷 연결이 끊겼어요" 표시 → 다시 연결되면 그대로 계속 |
| 학생이 새로고침 / 브라우저를 닫았다 다시 엶 | 같은 방 번호로 [참가하기] → 하던 경기로 바로 돌아감 (같은 기기면 같은 사람) |
| 경기 중에 새로 들어온 학생 | 이번 경기는 관전, 다음 경기부터 참가 |
| 교사 기기가 새로고침됨 | 학생 화면에 경고 → 교사가 다시 [교사용]→[방 만들기] 하면 **같은 방 번호**로 열리고 학생들이 그대로 남아 있음 |
| 인터넷이 아예 안 됨 | [혼자 연습하기]는 그대로 됨. 교사 방은 이 기기 안에서만 열리고 [+ 시험 학생]이 보임 |

### Firebase 준비 (처음 한 번)
1. Firebase 설정값은 `js/config.js`의 `FIREBASE`에 들어 있습니다. (웹 앱 설정값은 공개되어도 되는 값입니다)
2. Firebase 콘솔 → **Realtime Database → 규칙** 탭에 이 폴더의 **`firebase-rules.json` 내용을 통째로 붙여넣고 [게시]**.
   - 같은 Firebase 프로젝트를 다른 게임도 쓰고 있다면, 그 게임 규칙 덩어리는 지우지 말고 `"rules": { ... }` 안에 쉼표로 함께 두세요.
   - "테스트 모드"(날짜가 지나면 막히는 `now < ...` 규칙)는 지우세요. 날짜가 지나면 모든 게 막힙니다.
   - 규칙에 막히면 교사 대기방에 "Firebase 데이터베이스 규칙이 막고 있어요"라고 나옵니다.
3. 보안 규칙이 하는 일 (`firebase-rules.json`)
   | 막는 것 | 방법 |
   |---|---|
   | 다른 경로·전체 데이터 읽고 쓰기 | `circleBattle/rooms/{숫자 4자리}` 말고는 아무 규칙도 없음 = 모두 거부 |
   | 방 목록 훑어보기 (다른 반 닉네임 보기) | `rooms` 에는 읽기 규칙이 없음 → 방 번호를 아는 방 하나만 읽을 수 있음 |
   | 개인정보 칸 추가 (실명·전화번호 등) | 학생 칸은 `nick`(1~8글자)·`charId`·`at` 세 가지만 저장 가능, 그 밖의 칸은 거부 |
   | 이상한 값·모르는 칸 | 방 상태는 `lobby`/`playing` 만, 방 안에는 정해진 8개 칸(meta·players·roster·match·snap·in·kick·result)만 |
   | 닫힌 방 되살리기·찌꺼기 데이터 | 선생님 정보(meta)가 없는 방에는 아무것도 못 씀 → 방을 닫은 뒤 늦게 도착한 입력도 거부 |
4. **기록이 남지 않게**: 선생님이 대기방에서 [방 닫기]를 두 번 누르면 그 방의 닉네임·경기 기록이 **모두 삭제**됩니다.
   학생이 나가거나 연결이 끊기면 그 학생 칸도 자동 삭제됩니다.
   - 선생님이 [방 닫기] 없이 브라우저를 그냥 닫으면 방이 남습니다 (새로고침해도 같은 방으로 돌아올 수 있게 하려는 것).
     다음에 같은 기기에서 방을 만들면 그 방을 덮어쓰고, 3시간이 지난 방은 다른 선생님의 새 방이 덮어씁니다.
     수업이 끝나면 꼭 **[방 닫기]** 를 눌러 주세요.
   - 로그인(인증)이 없는 게임이라 "방 번호를 아는 사람"은 그 방에 쓸 수 있습니다. 그래서 학생에게 **실명 대신 별명**을 쓰게 해 주세요.
   - 학습 결과 CSV 는 선생님 기기에 내려받는 파일이며 Firebase 에는 저장되지 않습니다.

### 데이터 사용량 (무료 요금제로 충분)
- 경기 중 학생 기기 한 대가 받는 양: 조용할 때 1초에 약 4~6KB, 10명이 계속 싸우면 약 11KB (STEP 21 측정)
- 8분 경기 × 학생 9명 ≈ 20~50MB → 무료 한도(한 달 10GB)로 약 200경기 이상

### 시험용 주소
- `?test=1` : 인터넷이 되어도 교사 대기방에 [+ 시험 학생] 버튼 보이기
- `?dev=이름` : 한 컴퓨터의 여러 탭을 서로 다른 기기로 시험 (예: `index.html?dev=a`, `index.html?dev=b`)

## STEP 15 (교사용 방 생성)

화면 흐름: **시작 화면 [교사용] → PIN → 방 설정 → [방 만들기] → 교사용 대기방 → [게임 시작]**
- PIN은 `config.js`의 `TEACHER_PIN` 한 곳에서만 바꿉니다. (처음 값 `0000` — 꼭 바꿔 주세요)
  - GitHub Pages에서는 누구나 파일을 열어 볼 수 있으니 "학생이 실수로 들어오지 않게 하는 가벼운 잠금"으로 생각하세요.
  - PC에서는 키보드 숫자로도 입력, Esc는 취소
- 방 설정 12가지 (마지막으로 고른 값을 이 기기에 기억)
  | 항목 | 고를 수 있는 값 |
  |---|---|
  | 게임 시간 | 5 / 8 / 10분 |
  | 목표 점수 | 20 / 30 / 40점 |
  | 문제 난이도 | 쉬움 / 보통 / 어려움 |
  | 원주율 (수정 STEP 3) | 3.14 / 3 |
  | 점령 문제 시간 (수정 STEP 6) | 30 / 45 / 60초 (처음 값 30초) |
  | 수학 미션 수 | 한 학생당 3~6문제 |
  | 팀 크기 | 2 대 2 ~ 5 대 5 (넘치는 학생은 그 경기 관전) |
  | 같은 캐릭터 | 여러 명 가능 / 팀마다 한 명 |
  | 특수기 | 사용 / 사용 안 함 |
  | 재등장 시간 | 3 / 5 / 7초 |
  | 선생님 | 관전(TV 화면) / 함께 참가 |
  | 빈자리 채우기 | 봇으로 인원 맞춤 / 채우지 않음 |
- 교사용 대기방
  - 방 번호 4자리 (학생은 시작 화면에서 이 번호로 입장 — 실제 연결은 STEP 16)
  - 설정 한 줄 요약 + [설정 바꾸기] (방 안에서는 PIN 다시 묻지 않음)
  - 새 학생은 인원이 적은 팀으로 자동 배정, [팀 섞기]로 다시 반반, 이름을 누르면 반대 팀으로 옮김
  - 팀 크기를 넘는 학생에게는 "관전" 표시, 빈자리는 "+ 봇 N명" 미리 보기
  - 학생이 없으면 시작 버튼이 "학생을 기다리는 중"으로 잠김
  - [방 닫기]는 실수 방지를 위해 두 번 눌러야 닫힘
  - 경기가 끝나고 [대기방으로]를 누르면 같은 방 번호, 같은 팀으로 돌아옴
- 선생님 관전: 캐릭터 고르기 대신 안내가 나오고, 경기에서는 전체 화면 관전
- 선생님 참가: 선생님도 캐릭터를 고르고 한 팀에 꼭 들어감
  - 학생 9명 + 선생님 참가 → 5 대 5 (봇 없음)
  - 학생 9명 + 선생님 관전 → 5 대 4 + 봇 1 (봇은 STEP 21부터 존을 지키고 공격함)
- **[+ 시험 학생]** 은 가상의 학생을 넣어 보는 시험용 버튼입니다. (STEP 16부터는 인터넷이 안 될 때나 `?test=1`일 때만 보임)

## STEP 14 (대기방)

화면 흐름: **시작 화면 → 대기방 → 3·2·1 → 경기 → 결과 → [대기방으로]**
- 시작 화면: 닉네임(8글자까지), 방 번호(숫자 4자리), [참가하기], [혼자 연습하기], 오른쪽 위 [교사용]
  - 닉네임은 이 기기에 기억됨. 입력 칸에서는 W·A·S·D·H·F 같은 글자도 게임 조작 없이 그대로 입력됨
  - [참가하기]로 친구들과 같은 방에 모이는 것은 STEP 16(멀티플레이), [교사용]은 STEP 15에서 연결
- 대기방: 방 번호, 참가 인원, SOLAR·LUNAR 팀 목록(닉네임·캐릭터·"나"/선생님/봇 표시)
  - 캐릭터 6종 카드 + 능력치 막대(체력·속도·사거리·공격) + 기본 공격·특수기 설명 + 반지름별 비용
  - 시작 버튼은 방장(교사)만. 학생은 "선생님이 게임을 시작하기를 기다리는 중…"
  - "캐릭터 중복 허용"이 꺼져 있으면 같은 팀이 고른 캐릭터는 고를 수 없음
- 시작하면 3·2·1 카운트다운 (그동안 움직일 수 없음)
- 경기가 끝나면 [대기방으로] → 새로고침 없이 다음 경기 (점수·에너지·미션 수 모두 처음부터)
- 테스트 도구(캐릭터 바꾸기, 나에게 -30, ⚡ 가득)와 연습 상대는 "혼자 연습"에서만 나옴
- 개발 시험용: 주소 끝에 `?play=1`을 붙이면 시작 화면 없이 바로 혼자 연습 경기
  (`?view=spectate`, `?quick=1`도 바로 시작)

## STEP 10 (원형 범위 시스템)

  방금 바꾼 이전 원은 1.5초 동안 진하게 → 크기 차이가 한눈에
- 에너지 바: 미리보기 중에 이번에 쓸 만큼이 흰색으로 깜빡임 (모자라면 빨간색)

|---|---|---|
| 2m | 12.56㎡ | 13⚡ |

  - 스피더 순간이동: 반지름 6m 원 안 어디로든 (20⚡ 고정, 벽 안이면 가까운 빈 곳)
  - 엔지니어 원형 범위 터렛: 6m 안, 20초 동안 원 안 상대를 1초마다 자동 공격(8)
  - 프로스트 원형 둔화지역: 10m 안, 5초 동안 원 안 상대 이동속도 40% 감소
- 조작
  - PC: E 키(또는 마우스 오른쪽 버튼)를 누르고 있으면 미리보기 → 떼면 사용. Esc 취소. R 키로 반지름 바꾸기

## STEP 8 (점령과 팀 점수)

- 한 팀만 존 안에 있으면 점령 게이지가 차오름. 다 채워야 하는 양 = 존의 넓이(㎡)
  - 1명 기준: A존 약 9초, B존 약 17초, C존 약 26초 (2명 4.5㎡/초, 3명 5.5, 4명 이상 6)
  - 게이지는 안쪽 원의 "넓이"로 표시 → 50%일 때 안쪽 원 반지름은 약 0.71배
  - 존 안에 "39.2 / 78.5㎡" 처럼 채운 넓이 표시
- 두 팀이 함께 있으면 게이지 멈춤 (대치 중)
- 상대가 점령한 존: 상대 게이지를 0까지 깎아 중립 → 우리 팀 게이지를 채워 탈환
- 아무도 없으면 게이지가 초당 2㎡씩 제자리로 (주인 없는 존은 0으로, 점령된 존은 가득으로)
- 점령한 존: 테두리가 팀 색 실선, 바깥 흰 고리가 다음 점수까지 남은 시간
- 15초마다 A·B +1점, C +2점
- 승리: 목표 점수(기본 30) 먼저 달성, 또는 시간(기본 8분) 끝났을 때 점수가 높은 팀
- 동점이면 1분 연장전: A·B는 쉬고, C존을 먼저 점령한 팀이 승리. 그래도 안 나면 무승부
  (수정 STEP 6: 90초로 늘리고, 시간이 끝나면 C존 게이지를 채우던 팀 승리)
- 마지막 30초와 연장전에는 시간 표시가 빨갛게 깜빡임
- LUNAR 플레이어 화면에서는 우리 팀(LUNAR) 점수가 왼쪽
- 점령 기여도(게이지를 민 넓이 ㎡)를 개인 기록으로 모음 (결과 화면은 STEP 19)
- 빠른 시험: 주소 끝에 `?quick=1` → 1분 경기, 목표 10점, 5초마다 점수

## STEP 7 (에너지 존)

- 캐릭터 중심이 원 안(중심까지 거리 ≤ 반지름)에 있으면 "존 안"으로 판정
- 한 팀만 있으면 존이 그 팀 색으로 물들고, 두 팀이 함께 있으면 흰색으로 깜빡이며 "대치 중"
- 존 아래쪽에 팀별 인원 배지 (● 2  ● 1)
- 재충전 중인 캐릭터는 세지 않음
- 내 캐릭터가 존에 들어가면 위쪽에 넓이 구하는 식이 2.5초 동안 나타남
  예) C존에 들어왔어요 / 반지름 5m → 5 × 5 × 3.14 = 78.5㎡
- 화면 아래에 탄약·에너지 표시 자리를 따로 비워 맵을 가리지 않게 함

## STEP 6 (체력과 재등장)

- 캐릭터 위 체력바 (팀 색, 30% 이하면 빨강, 방금 깎인 부분은 흰색으로 천천히 줄어듦)
- 체력 0 → 에너지 조각이 흩어지며 사라짐 → 화면에 "에너지 충전 중 / 재충전 중... 5"
- 재등장 시간(기본 5초, config.js의 respawnSeconds) 뒤 자기 팀 시작 지역에서 체력·탄약 가득 채워 등장
- 재등장 직후 1.5초 보호 (맞아도 "보호" 표시, 피해 없음). config.js의 RESPAWN.PROTECT_SEC
- 충전 중에는 맞지 않고, 움직이거나 쏠 수 없음. 자동 조준도 충전 중인 상대는 건너뜀
- 테스트: H 키 또는 [나에게 -30] 버튼으로 내 캐릭터 재충전 시험

## STEP 5 (발사체 충돌)

- 탄이 벽·상자·기둥·터미널·경기장 테두리에 막힘 (부딪힌 자리에 불꽃)
- 상대 팀을 맞히면 탄이 사라지고, 맞은 캐릭터가 하얗게 반짝이며 피해 숫자가 떠오름
- 같은 팀과 쏜 사람 자신은 통과
- 가디언 충격파: 부채꼴 안의 상대를 한 명당 한 번만 맞히고, 벽 뒤는 맞히지 않음
- LUNAR 팀 "연습 상대" 4명이 서 있습니다 (2명은 위아래로 움직임, 1명은 상자 뒤). 멀티플레이를 연결하면 없앱니다.

## STEP 4 (조준과 기본 공격)

- `index.html`을 더블클릭하면 바로 열립니다. (서버 필요 없음)
- 벽·상자·기둥·터미널에 막히고, 비스듬히 부딪히면 벽을 따라 미끄러집니다.
- PC: 마우스로 조준, 왼쪽 클릭 또는 스페이스바로 발사
- 태블릿: 오른쪽 아래 공격 조이스틱
  - 끌어서 조준 → 손을 떼면 발사 (조준선이 사거리까지 보임)
  - 톡 누르기 → 사거리 안 가장 가까운 상대에게 자동 조준 (상대가 없으면 바라보는 방향)
  - 끌었다가 가운데로 되돌려 떼기 → 발사 취소
- 탄약 3발, 캐릭터마다 1발 충전 시간이 다름. 탄약이 없는데 쏘면 탄약 표시가 흔들림
- PC: WASD 또는 방향키로 이동. 한글 입력 상태여도 움직입니다.
- 태블릿: 화면 왼쪽 아래를 누르면 그 자리에 조이스틱이 나타납니다.
- 숫자키 1~6 또는 화면 아래 [테스트] 버튼으로 캐릭터를 바꿔 속도를 비교할 수 있습니다. (대기방이 생기면 없앱니다)
- 주소 끝에 붙이는 테스트 옵션
  - `?view=spectate` : 교사 관전 화면 (조작 없음)
  - `?touch=1` : PC에서 마우스로 조이스틱 시험
  - `?debug=1` : 충돌 상자(빨강)와 캐릭터 몸(초록) 보기
  - 여러 개를 함께 쓸 때는 `&`로 잇습니다. 예: `?touch=1&debug=1`

## 교사 참가 / 관전

방 설정 화면의 "선생님" 항목에서 고릅니다. (처음 기본값은 `config.js`의 `ROOM_DEFAULTS.teacherRole`)

| 설정 | 학생 9명일 때 | 교사 화면 |
|---|---|---|
| `'play'` (참가) | 교사 포함 5 대 5, 봇 없음 | 플레이 화면 + 호스트 역할 |
| `'spectate'` (관전) | 5 대 4 + 봇 1 = 5 대 5 | 전체 경기 관전 (TV 띄우기용) |

- 교사가 참가하면 인원이 꽉 차도 교사 자리는 꼭 확보됩니다.
- 결석생이 있으면 인원이 적은 팀에 봇이 자동으로 들어갑니다.
